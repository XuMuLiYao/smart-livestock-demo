# 智慧畜牧数字化管理与核心经营指标大屏 (Smart Livestock Demo)

本项目基于**现代畜牧标准化养殖**与数据闭环演算深度融合，构建以法定养殖档案（全套 81 张表）为底座的八大核心畜禽种类（生猪、奶牛、肉牛、奶山羊、肉羊、皮用羊、蛋鸡、肉鸡）经营决策交互式大屏看板。

---

## 🌟 核心功能亮点 (V3.2 全新升级)

1. **📊 在线数据处理与SPSS专业统计分析专区 (全新重磅上线)**：
   - **八大畜种专属 SPSS 变量元数据字典与语法导出**：深度对接 IBM SPSS Statistics 规范，系统内置八大畜禽（猪、奶牛、肉牛、奶山羊、肉羊、滩羊、蛋鸡、肉鸡）核心指标的变量名、中文标签、度量标准（Scale/Nominal）及小数位定义；支持网页端交互查阅，并提供官方标准语法脚本（`.sps`）与对齐数据文件（`.csv`）一键导出，实现双击直接在 SPSS 中完成数据编码导入；
   - **纯 Python / NumPy 高精度在线单因素方差分析 (One-Way ANOVA)**：自主研发无外部重量级依赖的统计学引擎（基于 Lanczos 伽马逼近与 Lentz 连分式不完全 Beta 积分算法），支持自由选定分组自变量与分析因变量，即时计算自由度、离均差平方和（SS）、均方（MS）、F 统计量与精确 P 值；自动生成符合国际顶刊投稿规范的**学术三线表**；
   - **事后多重比较与显著性字母标记 (Duncan / Tukey HSD)**：内置 Duncan/Tukey 多重比较算法，自动完成各实验组别均值降序排列与字母标记（如 a, b, ab 标记法），并同步绘制高清晰度组间均值与标准差**误差棒 (Error Bar) 柱状图**；
   - **全指标相关性热力图与多元线性回归 (MLR) 诊断**：自动生成生产与财务指标全矩阵 Pearson/Spearman 相关系数热力图；提供多元线性回归建模（OLS 最小二乘法），输出拟合优度 $R^2$、调整后 $R^2$、回归方程、系数显著性检验以及**方差膨胀因子 (VIF)** 多重共线性诊断；
   - **畜禽非线性生长模型拟合 (Gompertz & Logistic)**：专门针对肉牛、肉羊、肉鸡等肉用畜禽，内置经典 Gompertz 与 Logistic 非线性生长曲线方程，精准预测出栏理论成熟极限体重（$A$）与最大日增重拐点日龄（$t_i$）；
   - **智能大白话业务决策诊断转译**：告别晦涩统计术语，系统根据方差分析与回归结论自动输出可落地的养殖工艺调整建议与饲喂配方优化策略。
2. **八大核心畜种自定义上传模版全量供给与即时预览/下载体系**：
   - 全面覆盖**生猪、奶牛、肉牛、奶山羊、肉羊、皮用羊（滩羊）、蛋鸡、肉鸡**八大畜禽专属生产台账采集与指标测算上传模版（.xlsx）；
   - 每个模版均严格依循法定养殖档案标准设计，采用双工作表架构（`台账数据录入` 预置结构与基准示例值 + `填报说明与指标规范` 详细解释字段口径与容错逻辑）；
   - **双通道获取与即时交互**：在侧边栏第二步选择“上传自定义...”数据源时，提供专属模版一键下载按钮及展开式即时预览窗口（直接在网页查看字段与示例数值）；在底部“📥 测算结果与标准模版导出”板块亦同步支持全套模版下载与全景字段规范预览；
   - **容错隔离计算底座全面适配**：支持养殖场在本地修改数值或仅填报部分关键字段后直接上传，未采集字段自动容错隔离，好指标照常推演。
2. **全景平铺沉浸呈现与无滚轴视觉体验**：
   - 全局注入无滚轴样式，消除浏览器与容器滚动条干扰，保持平滑顺畅的无感滑动体验；
   - 默认启用“全景平铺模式”，彻底删除机械的“模块一至七”表述，替换为清晰专业的业务板块标题；
   - 升级分界线为略显著的渐变高对比度视觉线条，合理拉大不同板块之间的上下间距（45px/35px），使大屏通透大气、层级分明；亦可随时在顶部切换为标签选项卡模式。
3. **📰 行业新闻资讯与投稿互动中心 (全新升级：多环境管理员硬件指纹鉴权与敏感数据隔离保护)**：
   - 权威咨询门户直达：集成国家农业农村部畜牧兽医局、大畜牧网、猪场动力网、荷斯坦奶牛网、中国肉牛网、中国羊业网、中国禽业网、中国饲料工业信息网等一键直达；
   - 实时精选行业资讯动态：全面涵盖猪、牛、羊、禽政策调控、产能预警、疫病防控与饲料行情；
   - **增设「🔄 刷新资讯动态」按钮**，点击即可动态获取并展示最新行业资讯动态与更新时间戳；
   - **在线投稿数据自动持久化入库**：设立“留下工作个人联系方式上传咨询新闻及文章”通道，支持全畜种从业者在线登记联系方式并上传相关文档附件与咨询素材；用户提交后，系统自动将表单数据安全追加写入《行业新闻与咨询投稿登记表.xlsx》规范台账，同时将上传文档转存至本地《投稿附件》归档目录；
   - **🔐 管理员多重鉴权与隐私隔离保护**：为防止投稿人手机、微信、邮箱等敏感联系方式公开泄露，**普通用户网页端完全隐藏已登记投稿台账与导出按钮**，严格保护用户隐私；在侧边栏增设【🔐 管理员安全认证控制台】，支持本地物理硬件自动检测与云端公网访问预置凭据（李尧专属 MacBook Air 序列号 GP71L4XYJX / 物理 MAC 白名单）一键填充核验，双因子认证成功后方可解锁查看全景未脱敏台账并下载完整 Excel 工作簿。
4. **📚 行业权威学术论文与科研文献中心 (DOI 检索直达与畜禽数据库链接)**：
   - **内置 DOI 快速解析与一键直达检索器**，支持输入任意文献 DOI 号一键跳转国际 CrossRef 官方平台；
   - **直通 9 大核心畜禽科研数据库**：CrossRef、PubMed、Web of Science、CNKI 中国知网畜牧兽医专题库、JDS、JAS、Poultry Science、Small Ruminant Research、Meat Science 一键直达；
   - **八大畜禽专属高被引经典与前沿论文精选库**：精选顶级期刊代表性文献，标明中英文双语题名、作者、期刊年份、核心研究点及标准化 DOI，支持一键点击直达原文。
